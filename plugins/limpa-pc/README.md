# limpa-pc

Painel "Limpeza do PC" para o Claude no Windows, feito para quem não é técnico. Abre ao lado do chat (ou com `/limpar-pc`):

1. **Ver como está meu PC**: memória, discos, programas pesados. Não muda nada.
2. **Ver o que ocupa espaço nos discos**: lê SSD/NVMe/HD e separa tudo em 🟢 verde (lixo seguro: caches do Premiere, After Effects, DaVinci, cópias automáticas antigas), 🟡 amarelo (projetos parados, proxies, duplicados, instaladores) e 🔴 vermelho (brutos, projetos, vídeos finais, documentos). Não apaga nada.
3. **Limpar e acelerar o Windows**: temporários, caches, ponto de restauração, energia, TRIM. Pede um "Sim" do Windows.

Depois do mapa: **Apagar só o lixo verde**, **Revisar o amarelo com a especialista** (no chat, item por item, indo para uma quarentena que dá para desfazer) e **Ligar manutenção automática** (todo domingo).

Precisa rodar no Claude instalado no computador Windows, não numa sessão na nuvem.
