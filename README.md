## Mod "Limpeza do PC" (painel dentro do Claude)
No Claude instalado no seu PC Windows, digite:

```
/plugin install limpa-pc --marketplace davibsmabruk-alt/MASTER-MABRUK
```

Responda `y` e escolha onde instalar. O painel "Limpeza do PC" abre ao lado do chat (ou digite `/limpar-pc`).
